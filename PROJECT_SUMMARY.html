3Gameplay Loop and Controls

Game.update(dt) (when playing) executes:

  • Continuous winch key-hold logic (Shift/Ctrl + rope letter).
  • Physics step with 20 substeps.
  • Candy animation update (squash/stretch).
  • Target animation update (mouth/swallow state).
  • Teleport cooldown updates.
  • Magnet proximity check and dynamic rope spawn.
  • Spider rope crawling and catch checks.
  • Off-screen fail check (y < -100, x < -100, x > 820).
  • Renderer update (particles + stars).

4Physics and Rope System

Engine: Pymunk space with gravity (0, -900), damping 0.92, iterations 30.

Rope construction

  • Rope segment count: max(2, int(length / 35)).
  • Each segment: dynamic body + sensor segment shape + PinJoint + DampedRotarySpring.
  • Rope shapes share a collision filter group, so rope segments do not collide with each other.
  • First joint links anchor to first segment; final PinJoint links last segment to candy.

Winch adjustment

adjust_winch_rope() rescales PinJoint distances and local anchors, updates segment endpoints, and stiffens rotary springs as rope retracts. This avoids unstable force spikes during rapid length changes.

Collision callbacks and safety

  • Callbacks are queued in _post_step_actions and flushed after stepping to avoid mutating space while locked.
  • Rope segment velocity is clamped to 1500 px/s to prevent explosive behavior.

8Persistence and Data Files

src/savedata.py manages score and custom-level persistence.

Score model (current write path)

  • data/scores.json numeric level keys like "0": {"time": 2.91}.
  • On win, score is saved only if new time is better.
  • Star count is derived from per-level star_times thresholds.

Custom levels

  • data/custom_levels.json stores a list of level dicts compatible with Game.
  • Current repository file is empty ([]), ready for editor-generated levels.

Compatibility note

Existing scores.json includes legacy keys (campaign_x) alongside current numeric keys. Current gameplay reads numeric level indices for campaign best-time display.
